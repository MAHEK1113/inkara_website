# inkara_website
📚 Inkara – Mood-Based Book Discovery Platform

🌟 Overview
Inkara is a thoughtfully designed web platform for book lovers that helps users discover books based on their mood, interests, and favorite authors.
It transforms reading into a more personal and emotional experience by connecting readers with stories that truly resonate.

✨ Features
🎭 Mood-Based Recommendations – Find books based on how you feel
✍️ Author Explorer – Discover books by your favorite authors
📖 Book Library – Browse a curated collection of books
❤️ Wishlist – Save books to read later
📱 Responsive Design – Works across devices
🎨 Vintage Aesthetic UI – Elegant and immersive reading experience

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Design: Custom CSS (Vintage theme)
Functionality: DOM Manipulation, Dynamic Rendering
